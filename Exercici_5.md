# Observa aquests dos fragments que guarden exactament la mateixa informació sobre tasques quotidianes:
### ***Quina de les dues opcions és més ràpida d'escriure i més fàcil de llegir per a un humà quan s'obre el fitxer en un editor de text pla sense cap visor?***
De les dues opcions que son XML o Markdown, pel que he après, el més ràpid i més fàcil de llegir per a un humà és el Markdown. Ja que qualsevol persona pot entendre això amb poca pràctica, ja que només amb escriure un guió, els claudàtors i el text de la tasca, amb el resultat d'això ja es pot saber si la tasca està feta o no. I si utilitzes XML has d'fer servir etiquetes d'obertura, de tancament per a cada cosa, també t'obliga a posar un atribut.

### ***Si l'Opció B és tan simple, per quina raó un sistema informàtic o una base de dades preferiria rebria/processar la informació en format XML (Opció A) quan s'envien dades entre servidors?***
La raó de per què un sistema informàtic o una base de dades preferiria utilitzar XML quan s'envien dades entre servidors és perquè XML ja té una estructura, o sigui té una estructura estricta i definida, per això si fa servir XML permet que una màquina processi sense equivocar-se, ja que les etiquetes diuen exactament que és cada dada. Una altra manera de dir-ho, XML serveix per guardar i intercanviar dades, mentre que Markdown serveix per donar format al text.
