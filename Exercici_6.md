# Per què creus que Markdown és l'estàndard dels README.md a GitHub?
Jo crec que és l'estàndard dels README.md perquè Markdown és molt fàcil de llegir i ràpid d'escriure com he dit abans, llavors no fa falta utilitzar ni saber d'HTML ni cap programa especial. El README en veritat el pot escriure qualsevol persona amb un editor de text simple, ja que només has d'escriure, i com el fitxer és text pla, es pot llegir superfàcil encara que no estigui renderitzat. I això en el GitHub funciona superbé, perquè es poden veure fàcilment els canvis entre versions. Després GitHub el que fa se'l renderitza automàticament a la portada del repositori, amb títols, llistes, taules, enllaços i blocs de codi amb colors.
